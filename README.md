# Cambridge B1 Preliminary (PET) - Ôn Luyện Toàn Diện 12 Đề Thi 🎓

Ứng dụng web ôn thi chứng chỉ Cambridge B1 Preliminary (PET) toàn diện với đầy đủ 4 kỹ năng (Reading, Writing, Listening, Speaking), Flashcards từ vựng và hệ thống thi thử mô phỏng CBT.

---

## 🌟 Tính Năng Nổi Bật

1. 💻 **Thi Thử CBT (Computer-Based Test):**
   - 12 Đề thi thử hoàn chỉnh chuẩn format Cambridge B1 Preliminary.
   - Giao diện làm bài trực tuyến, bấm giờ thi thật, tự động chấm điểm và xem lời giải chi tiết.

2. 🎧 **Luyện Nghe Audio (Listening Lab):**
   - Đầy đủ 4 phần (Part 1 - Part 4) với file âm thanh chuẩn.
   - Hình ảnh minh họa trực quan cắt từ đề thi gốc.
   - Hiển thị tapescript và giải thích đáp án chi tiết.

3. ✍️ **Luyện Viết (Writing Studio):**
   - Luyện viết Part 1 (Email) và Part 2 (Article/Story).
   - Bài mẫu band điểm chuẩn Cambridge, hướng dẫn từng bước và gợi ý cấu trúc câu ăn điểm.

4. 🗣️ **Luyện Nói (Speaking Arena):**
   - Trọn vẹn 10 bộ đề thi nói với 4 phần (Part 1 Phỏng vấn, Part 2 Thảo luận theo tranh, Part 3 Miêu tả 2 bức ảnh màu gốc, Part 4 Thảo luận mở rộng).
   - Từ vựng & câu trả lời mẫu được biên soạn sát trình độ B1 (đơn giản, tự nhiên, dễ áp dụng).
   - Tích hợp giọng đọc AI Text-to-Speech (Anh - Anh / Anh - Mỹ) cho câu hỏi giám khảo và câu trả lời mẫu.

5. 🗂️ **Flashcards & Từ Vựng:**
   - Hơn 1000+ từ vựng cốt lõi B1 kèm phát âm, nghĩa tiếng Việt và câu ví dụ theo ngữ cảnh đề thi.

6. 📚 **Thư Viện 12 Đề & Phân Loại 12 Unit:**
   - Tra cứu đáp án, tapescript và bản PDF/Scan dễ dàng.

## 🚀 Hướng Dẫn Chạy Cục Bộ (Local)

Chỉ cần mở file `index.html` trên trình duyệt:
- Cách 1: Kích đúp vào file `start_app.bat` hoặc `index.html`.
- Cách 2: Dùng Live Server hoặc chạy lệnh:
  ```bash
  python -m http.server 8080
  ```
  Sau đó truy cập `http://localhost:8080` trên trình duyệt.

## 🌐 Triển Khai Miễn Phí Lên GitHub Pages

Trang web thuần HTML, CSS, JavaScript (Static Web), hoàn toàn tương thích và chạy mượt mà trên **GitHub Pages**:
1. Đẩy mã nguồn lên repository GitHub của bạn.
2. Vào **Settings** > **Pages**.
3. Tại **Build and deployment** > **Branch**, chọn `main` (hoặc `master`) và thư mục `/(root)`.
4. Nhấn **Save**. Sau 1 phút, bạn sẽ nhận được đường link web trực tuyến miễn phí!
